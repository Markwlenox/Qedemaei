# qedemaei.com

The Qedemaei / Logan Chronicles website, served by GitHub Pages.

- `index.html`: the page (the book shelf, then the opener and the scrolling introduction)
- `story-data.js`: every caption in the scrolling introduction, in order. Edit words here.
- `story.css`, `story.js`: the look and behavior of the opener and the scroll
- `media/logan-chronicles-opener.mp4`: the opener with the narration mixed in
- `media/story/`: the pictures, each in a full size and a `-sm` phone size (WebP)

To preview locally, open `index.html` in a browser.
